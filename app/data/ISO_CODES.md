# ISO reference data

Flask-AAS vendors the following reference-data files from the `iso-codes` project:

- `iso_3166-1.json` — ISO 3166-1 countries
- `iso_3166-2.json` — ISO 3166-2 country subdivisions

Development source used for this snapshot: Fedora `iso-codes` package 4.17.0-2.fc42.
Upstream project: https://salsa.debian.org/iso-codes-team/iso-codes

The `iso-codes` project is distributed under LGPL-2.1-or-later. Keep this note with
vendored snapshots and refresh both JSON files together when updating the catalog.
